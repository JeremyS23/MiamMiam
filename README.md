# 🍳 MiamMiam

Application web full-stack d'affichage et de gestion de recettes de cuisine développée en TypeScript, React et Node.js par **Jeremy Semblantes**

## 🛠️ Stack Technique

- **Frontend** : React, TypeScript, Vite, CSS3
- **Backend** : Node.js, Express, REST API
- **Données** : Fichiers JSON (`recipes.json`, `categories.json`, `users.json`)

---

## 📁 Structure du Dépôt

```text
MiamMiam/
├── frontend/           # Application client React / TypeScript
│   ├── src/
│   │   ├── components/ # RecipeCard, RecipeList, PageLayout...
│   │   ├── App.tsx
│   │   └── main.tsx
│   └── package.json
└── MiamMiam-backend/   # API REST Express / Node.js
    ├── data/           # Fichiers de données
    ├── src/            # Contrôleurs, routes, middlewares
    └── package.json
```
